## Description

A simplified version of AirBNB built with Laravel, featuring user authentication, property listings, and booking functionality. This project allowed me to deepen my understanding of Laravel's features and best practices, while also improving my skills in PHP and OOP.

## What I learned

- Laravel framework and its features
- Eloquent ORM for database interactions
